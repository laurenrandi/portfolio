    VR/ML Language Learning

    A Virtual Reality Language Learning Project

    About The Project

    Overview

    The VR/ML Language Learning Project explored the use of virtual reality and machine learning technologies for language learning.

    The project combined an immersive virtual environment with interactive learning experiences to investigate how technology could be used to support language education.

    I worked on the project as part of a research experience, developing virtual reality components and exploring how different technologies could be incorporated into the learning experience.

    Virtual Reality

    Created an interactive virtual environment designed to support an immersive learning experience.

    Language Learning

    Explored ways that interactive virtual environments could be used to support language learning.

    Machine Learning

    Explored the role of machine learning within the language learning research project.

    Development Process

    Documentation

    This project was developed as part of a research experience focused on the intersection of virtual reality, machine learning, and language learning.

    I used Blender to work with 3D assets and Unity to create and develop the virtual reality environment.

    C# was used within Unity to implement interactive functionality for the virtual environment.

    The project also involved documenting the research and development process using Overleaf.

    Tech Stack

    Unity — Used to develop the interactive virtual reality environment.

    C# — Used to implement functionality and interactions within Unity.

    Blender — Used for working with 3D models and assets.

    Overleaf — Used to write and organize the research documentation.

    Machine Learning — Explored as part of the language learning research.

    Reflection

    What I Learned

    What I Learned

    This project gave me experience developing interactive virtual reality environments and working with 3D assets.

    I strengthened my understanding of C# through implementing interactive functionality in Unity.

    I also gained experience working with Blender and incorporating 3D assets into a virtual environment.

    The research process helped me become more comfortable documenting technical work and exploring unfamiliar technologies.

    Most importantly, the project allowed me to explore how multiple areas of technology can be combined to create an interactive learning experience.
