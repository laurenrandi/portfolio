    Croptails

    A video game project developed while learning game development

    About The Project

    Overview

    Croptails is a video game project that I developed while learning more about game development and interactive programming.

    The project gave me an opportunity to work through the process of building a playable game while learning how different systems work together.

    Rather than being created entirely from scratch, this project was developed as a follow-along project, allowing me to practice implementing concepts and understanding how the different parts of a game are constructed.

    Gameplay

    A playable game environment where the player can interact with the world and its systems.

    Game Systems

    Practice implementing the different systems needed to make the game function as an interactive experience.

    Game Development

    Hands-on experience following a game development workflow and understanding how individual components work together.

    Documentation

    Croptails was developed as a follow-along game development project. The project allowed me to learn by working through the development process and implementing the concepts demonstrated in the tutorial.

    Working through the project helped me become more familiar with the structure of a game and how different gameplay systems, assets, and interactions fit together.

    I also used the project as an opportunity to practice troubleshooting and understanding the code rather than simply treating the tutorial as something to copy.

    Tech Stack

    Game Engine — Used to build the game environment, gameplay systems, and interactive elements.

    Programming — Used to implement gameplay functionality and interactive behavior.

    Git / GitHub — Used for version control and managing the project code.

    What I Learned

    This project gave me practical experience with game development and helped me better understand how individual gameplay systems work together.

    Following the project from start to finish also helped me practice reading and understanding existing code, implementing new functionality, and troubleshooting problems along the way.

    Most importantly, it gave me experience working outside of traditional web development and helped me become more comfortable learning unfamiliar tools and development workflows.
