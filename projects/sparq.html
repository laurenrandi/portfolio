    Sparq Colleague Profile Builder

    A Full Stack Web Application

    About The Project

    Overview

    The Sparq Colleague Profile Builder is a full stack web application developed as a senior capstone project.

    The application was designed to allow colleagues to create and manage professional profiles containing information about their skills, experience, and professional background.

    The project provided experience working across the front end, back end, and database layers of a web application while integrating multiple technologies into one system.

    Profile Builder

    Allows users to create and manage their professional colleague profiles.

    Full Stack Application

    Connects a React front end with back-end services and a PostgreSQL database.

    Data Management

    Uses a database to store and retrieve information associated with colleague profiles.

    Development Process

    Documentation

    The Sparq Colleague Profile Builder was developed as a full stack application, requiring the front-end interface, back-end services, and database to work together.

    I worked with React to develop the user interface and create the application's interactive components.

    The back end was developed using Node.js, while PostgreSQL was used to store and manage application data.

    The project also provided experience working with Java Spring as part of the application's back-end development environment.

    Tech Stack

    React — Used to build the front-end interface and interactive components.

    Node.js — Used for back-end development and application functionality.

    Java / Spring — Used as part of the application's back-end development.

    PostgreSQL — Used for storing and managing application data.

    NPM — Used for managing JavaScript packages and project dependencies.

    Git / GitHub — Used for version control and collaborative development.

    What I Learned

    This project strengthened my understanding of full stack web development and how different layers of an application communicate with one another.

    I gained experience building React interfaces while also working with back-end technologies and a relational database.

    Working on a larger application also helped me become more comfortable navigating an existing codebase and understanding how individual components fit into a larger system.

    The project also gave me experience with collaborative software development and working toward a larger application as part of a team.
