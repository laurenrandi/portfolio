    Randi's Creative Corner

    A personal creative library and digital scrapbook

    About The Project

    Overview

    Randi's Creative Corner is a personal creative library designed to give me a place to collect, organize, and display the things I create and enjoy.

    The project is designed to feel more like a personal digital scrapbook or virtual library than a traditional social media platform.

    The goal is to create a space where creativity can be documented without the pressure of likes, followers, or comparison.

    Creative Library

    Organize photography, artwork, crafts, outfits, videos, and personal thoughts in one personal space.

    Interactive World

    Explore a virtual world where different destinations represent different areas of creativity.

    Personal Media

    Creative entries can include images, videos, music, stickers, and other personal media.

    Development Process

    Documentation

    This project began as an idea for a personal creative space that would feel different from traditional social media.

    Instead of focusing on public engagement, the project is centered around collecting and displaying my own creative work.

    I designed the visual environment myself and began developing the application using Next.js and React.

    The project has also involved experimenting with custom illustrations, interactive interfaces, 3D environments, and game-like interactions.

    Tech Stack

    Next.js / React — Used to build the web application, routing, and interactive components.

    JavaScript / CSS — Used for interactive functionality and visual design.

    Git / GitHub — Used for version control and managing the project code.

    Blender — Used to create and prepare 3D assets for the project.

    What I Learned

    This project has given me experience building a larger application from an idea of my own, rather than following an existing project or tutorial.

    I have learned more about React and Next.js, organizing a larger application, creating interactive interfaces, and working with custom visual assets.

    I have also been able to experiment with 3D environments and think about how traditional websites can incorporate more game-like experiences.
